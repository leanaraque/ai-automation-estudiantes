# AI Automation — Repositorio de clase

Material de apoyo de las clases en vivo del curso **AI Automation** de Coderhouse.

Acá vas a encontrar, semana a semana, las guías paso a paso de lo que construimos en clase, los datos de prueba y los textos (prompts, mensajes) listos para copiar.

## Cómo usar este repositorio

- Cada semana tiene su carpeta. Entrá a la de la clase y empezá por su `README.md`.
- Las guías están numeradas en el orden en que conviene hacerlas.
- Si algo no te funciona, revisá primero la sección **"Si algo falla"** al final de cada guía.

## El caso que trabajamos en todo el curso: Agencia Norte

Todas las clases giran alrededor de un mismo negocio ficticio, para que cada tema nuevo sea una pieza más de un sistema que ya conocés.

**Agencia Norte** es una agencia chica de diseño web y marketing digital. Recibe consultas de posibles clientes (leads) por correo. Su problema: las consultas urgentes se pierden entre el resto y, cuando alguien las ve, el cliente ya contrató a otra agencia.

Semana a semana vamos a automatizar su proceso comercial, de punta a punta.

## Reglas de oro para todo el curso

1. **Nunca subas tus claves** (API keys, tokens, contraseñas) a un repositorio, a un chat ni a una captura de pantalla. Si se te filtra una, revocala y generá otra.
2. **Probá con datos de prueba**, nunca con datos reales de clientes.
3. **Guardá tu trabajo**: exportá tu escenario (Make) o tu workflow (n8n) al final de cada clase.
